بيانات اللعبة

املأ البيانات، وهتطلع لك سطر جاهز تلصقه في الموقع.

الخطوات

بعد ما تملأ البيانات اتبع الخطوات دي:

املأ اسم اللعبة الأول…
  1. افتح ملف extra-games.js على GitHub واضغط على القلم (Edit).
  2. الصق السطر تحت كلمة «ضيف هنا» واضغط Commit changes.
  3. ارفع البوستر اللي نزّلته جوه فولدر images (Add file ← Upload files).
  4. استنى دقيقة وحدّث الموقع.

جهّز بوسترات كتير مرة واحدة

اختار صور الأغلفة اللي معاك (حتى لو أسماءها مختلفة). الأداة بتحاول تطابق كل صورة مع لعبتها، وانت بتصحّح لو غلطت، وبعدين تنزّل ملف واحد فيه كل الصور بالأسماء الصح.

  1. فك ضغط الملف على جهازك.
  2. على GitHub افتح فولدر images واضغط Add file ← Upload files، واسحب كل الصور اللي طلعت بعد فك الضغط.
  3. اضغط Commit changes واستنى دقيقة.
