غير متصل الموقع ←
🔑 ربط اللوحة بالموقع (مرة واحدة بس)

المفتاح بيتحفظ على جهازك أنت بس، ومحدش يقدر ينشر في الموقع من غيره. ما تبعتوش لأي حد.

  1. ادخل على GitHub ← صورتك ← Settings ← Developer settings ← Personal access tokens ← Fine-grained tokens ← Generate new token.
  2. اكتب أي اسم، واختار مدة الصلاحية (الأطول أحسن)، وفي Repository access اختار Only select repositories وحدد ريبو الموقع بس.
  3. في Permissions ← Repository permissions خلّي Contents على Read and write.
  4. اضغط Generate، وانسخ المفتاح والصقه تحت.
